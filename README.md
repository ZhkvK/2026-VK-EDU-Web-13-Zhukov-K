## Домашнее задание №1

**Чтобы открыть вёрстку** с гланой страницы, откройте файл `public/index.html` в браузере.

### Список страниц:
- `public/index.html` и `public/base.html` - список вопросов (главная) 
- `public/question.html` - страница одного вопроса
- `public/ask.html` - страница создания вопроса
- `public/login.html` - страница входа
- `public/signup.html` - страница регистрации
- `public/profile.html` - страница профиля (перейти из других страниц нельзя)
